# omalauncher-tools

Widgets and helper scripts for [omalauncher](https://github.com/SimonSchubert/omalauncher),
one folder per tool. The phone's live copy is `CloudStrife7/omalauncher-config`; these folders
are the tool kept on its own, with the story of how it was made.

| Folder | What it is |
|---|---|
| `tv-remote/` | Remote widget for a Sony BRAVIA Android TV. `tv.owl` is the widget, `tv-remote` is the script it runs, `INSTALL-tv.md` is what Claude follows to install it, `transcripts/` holds the two sessions that built it (part 1: PC, part 2: phone). |
